# Platform Cut Specs

Edit this file to change how cuts are made. The skill follows whatever is here.

## YouTube (description + chapters)

- Description: 2-3 sentences, front-load keywords in sentence one (only the first ~150 chars show uncollapsed)
- Chapters: timestamped, first chapter at 0:00, chapter titles are outcomes ("Deploy in one command"), not labels ("Part 3")
- Links: CTA link first, then resources mentioned
- 3-5 hashtags maximum, below the fold

## LinkedIn post

- 150-300 words
- First line is the hook and must survive the "...see more" fold (~200 chars)
- Short paragraphs, 1-2 sentences each; white space is structure
- No external link in the body if reach matters — CTA as "link in comments" or a soft ask
- Professional but not corporate; first person; one idea per post
- 0-3 hashtags

## X / Twitter thread

- 5-8 posts maximum
- Post 1 = hook standing fully alone (would work with zero replies)
- One idea per post; code screenshots beat code blocks
- Last post = CTA + link
- No "🧵 1/12", no "thread below" — just start

## TikTok / Shorts / Reels script

- 30-60 seconds, scripted word-for-word
- Hook in the first 2 seconds: outcome or controversy, never an intro
- Spoken register — write for the mouth, not the eye
- On-screen text callouts noted in [brackets]
- CTA verbal + on-screen at the end
- Requires a visual moment; if the source has none, skip this cut

## Blog intro / cross-post excerpt

- 100-200 words: the core claim + why it matters + "read the full piece" link
- Written as a standalone teaser, not the source's first paragraphs copied
- Canonical link back to the original
